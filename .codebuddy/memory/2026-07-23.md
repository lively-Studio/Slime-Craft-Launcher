## HMCL 项目：移除平台特定构建，仅保留 JAR 构建

1. **HMCL/build.gradle.kts**：移除了 `makeExecutables`（EXE/SH）和 `makeDeb`（DEB）任务及相关代码，包括 `launcherExe` 变量、`HMCLauncher` 依赖、`artifactFile` 函数、`CreateDeb`/`ReleaseType` 导入，以及 `build` 任务对平台打包的依赖。

2. **gradle/libs.versions.toml**：移除了 `hmclauncher` 版本声明和库声明。

3. **buildSrc/build.gradle.kts**：移除了 `kala.compress.ar` 依赖（仅被已删除的 CreateDeb 使用）。

4. **config/jenkins/dev/Jenkinsfile** 和 **config/jenkins/stable/Jenkinsfile**：将 `makeExecutables makeDeb` 改为 `build`。

5. **删除的文件**：
   - `buildSrc/src/main/java/org/jackhuang/hmcl/gradle/pack/CreateDeb.java`
   - `buildSrc/src/main/java/org/jackhuang/hmcl/gradle/pack/ReleaseType.java`
   - `HMCL/src/main/java/org/jackhuang/hmcl/upgrade/ExecutableHeaderHelper.java`

## NOTHING-UI-1 主题重做

基于 `github.com/Open-code-Studio/NOTHING-UI-1` 的 DESIGN_SPEC.md 设计规范，全面重做了 HMCL 的 UI 主题。

### 设计规范来源
- 仓库：Open-code-Studio/NOTHING-UI-1 DESIGN_SPEC.md v1.0
- 补充参考：dominikmartn/nothing-design-skill 设计规则

### 核心设计变更

**色彩系统**：从 Material You / MonetFX 动态色彩 → NOTHING-UI-1 静态令牌
- 6 层 Surface 系统（Dark: #0A0A0A~#252525, Light: #F5F5F5~#D4D4D4）
- 4 级文字透明度（100%/90%/60%/35%）
- 强调色：Cyan #00BCD4（默认）/ Green #4CAF50 / Orange #FF9800
- 错误色：Red #D71921（仅作信号，不参与常规层级）
- 轮廓线：rgba(255,255,255,0.12)

**排版**：字体栈 Inter → SF Pro Text → Segoe UI → Roboto，等宽 JetBrains Mono
**圆角**：默认 2px，弹窗 4px
**动画**：≤200ms，无弹跳
**阴影**：5 层冷色阴影（gaussian, 无模糊扩散）
**按钮**：32px 高度
**进度条**：4px 高度
**卡片**：2px 圆角 + surface-2 背景 + 层叠阴影

### 修改的文件
1. **新建 `nothing-ui.css`**：定义所有 NOTHING-UI-1 设计令牌（色彩、文字、间距、阴影等 CSS 变量）
2. **重写 `root.css`**（~2000行）：所有组件样式使用 NOTHING-UI-1 令牌替代原有 `-monet-*` 变量
3. **重写 `brightness-dark.css`**：暗色模式 Surface 引用
4. **重写 `brightness-light.css`**：亮色模式 Surface 引用
5. **更新 `font.css`**：排版改为 NOTHING-UI-1 字体栈（Inter 优先级）
6. **更新 `StyleSheets.java`**：移除 MonetFX 动态色彩生成（ColorRole/ColorScheme/ThemeColor），主题样式表固定为 `/assets/css/nothing-ui.css`

### 亮色模式切换
用户反馈设计是黑的不是白的，将 NOTHING-UI-1 默认从暗色翻转为亮色。
- `nothing-ui.css`：Surface 默认值从 #0A0A0A~#252525 → #F5F5F5~#D4D4D4，文字从 rgba(255,255,255,*) → rgba(0,0,0,*)
- `root.css`：批量替换所有硬编码暗色值 → 亮色等价（rgba(255,255,255,N) → rgba(0,0,0,N)，rgba(10,10,10,N) → rgba(245,245,245,N)）
- 保留暗色的例外：`.bubble`、`.tooltip`（提示框始终暗底白字）、`.jfx-button-raised`（强调按钮白字）

### 亮色主题标题栏和选中项对比度修复
用户反馈两个视觉问题：
1. 标题栏白底白字看不清 → 根因是 `getBrightnessStyleSheet()` 跟随系统暗色模式加载了 `brightness-dark.css` 覆盖亮色默认值
2. 选中按钮 accent 背景与 accent 文字/图标同色看不清 → accent 背景不透明度太低(8%)

修复：
- `StyleSheets.java`：强制始终加载 `brightness-light.css`，不再跟随系统暗色模式
- 移除 `Brightness` import
- `root.css`：`.jfx-tool-bar.background`、`.jfx-tool-bar-second` 背景从 accent 改为 neutral surface
- `.jfx-tool-bar-second .label` 文字从 accent → `-nothing-on-surface`（黑字）
- `.jfx-decorator-title` 增加显式 `-fx-text-fill: -nothing-on-surface`
- `.advanced-list-item:selected` 和 `.game-directory-list-item:selected` 背景不透明度 8% → 15%

### 保真模式浅色标题栏文字修复
`DecoratorSkin.java` 中标题文字通过 `Themes.titleFillProperty()` 绑定（Java 代码，不走 CSS）。
当色彩模式为"保真"且浅色时，`titleBarTransparent=false`，`titleFill` 使用 `getOnPrimaryContainer()`，
这个颜色可能在浅色 surface 背景上对比度不足。
修复：`Themes.java` 中 `titleFill` 非透明分支从 `getOnPrimaryContainer()` 改为 `getOnSurface()`，
保证标题文字始终适配窗口背景色。

### 恢复亮暗色模式自动切换
用户反馈切换暗色模式后 UI 仍是浅色背景，仅文字变浅（白底白字不可读）。
根因：之前将 `getBrightnessStyleSheet()` 强制固定为 `brightness-light.css`，且 `root.css` 中颜色值为硬编码。

重构方案：所有颜色值从硬编码改为引用 `-nothing-*` CSS 变量，由 `brightness-dark.css` / `brightness-light.css` 切换。
- `nothing-ui.css`：新增 12 个亮暗色动态令牌（ripple-fill, hover-bg, scrollbar-thumb/arrow, overlay-bg, card-bg, bubble-bg, acc-track-bg, toolbar-bg, toolbar-second-bg/label 等）
- `root.css`：所有 `rgba(...)` 颜色值替换为 `-nothing-*` 变量引用
- `brightness-dark.css`：完整暗色变量覆盖（surface+text+outline+所有动态令牌+log-window）
- `brightness-light.css`：完整亮色变量值（默认值）
- `StyleSheets.java`：恢复 `Brightness` 检测，根据系统/设置自动切换 CSS

## 2026-07-24 补充

### 自动排除无法创建子进程的 Java
macOS 上某些 JDK（如 Zulu 21.0.11）`posix_spawn` 有缺陷，无法创建子进程，导致无法启动 Minecraft。
- `JavaInfoUtils.canSpawnProcess()`：尝试运行 `true` 命令，缓存结果（package-private，供 `JavaManager` 调用）
- `JavaManager.searchPotentialJavaExecutables()`：搜索完成后检查，false 时返回空 Map + 警告日志
- `JavaManager.getAddJavaTask()`：手动添加 Java 时拒绝，抛 IOException
- `JavaInfoUtils.fromExecutable()`：进程不可用时回退到解析 JDK `release` 文件
- 自动检测 release 文件路径：macOS `Contents/Home/release`，标准 `$JAVA_HOME/release`
- 6 个 Monet CSS 变量残留已全部替换为 `-nothing-*`（inline style 导致的 ClassCastException）
- 5 个 Java 安装崩溃点已修复（空归档、符号链接、静默异常、getFileStore、toRealPath）
- 添加 NBT Viewer 侧边栏按钮
