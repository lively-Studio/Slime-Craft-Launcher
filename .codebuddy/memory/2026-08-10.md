# 2026-08-10

## 拓展/插件系统实现
基于 GitHub Issue #1 (Feature: 拓展功能)，为 SCL 实现了完整的插件系统。

### 新增文件
- SCLCore/plugin/: Plugin.java, PluginDescriptor.java, PluginState.java, PluginClassLoader.java, PluginManager.java, ExtensionPoint.java, PluginPageProvider.java, PluginDownloadSourceProvider.java, PluginThemeProvider.java, PluginStateChangeEvent.java (共10个)
- SCL/ui/plugin/PluginListPage.java

### 修改文件
- Controllers.java: 添加 pluginListPage Lazy 实例和 getPluginListPage() 方法
- RootPage.java: 导航栏添加拓展页面入口 (SVG.EXTENSION 图标)
- Launcher.java: initializeSettingsRuntime() 中初始化 PluginManager, stopApplication() 中 shutdown
- I18N.properties / I18N_zh_CN.properties: 添加 plugin.* 翻译 key (中英文共约16条)

### 设计要点
- 插件从 $SCL_USER_HOME/plugins/*.jar 加载
- 每个插件使用独立 PluginClassLoader 隔离
- 支持 3 种扩展点: 页面、下载源、主题
- 自动发现并加载所有插件，UI 页面可管理插件状态
